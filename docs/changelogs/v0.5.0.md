# Kibtab v0.5.0

Released: Not released. Commit: none.

Version 0.5.0. This file holds the changes for the HTTP API release.

## Added

* `internal/adapters/driver/http/` holds the HTTP transport.
* The route `GET /v1/tables` lists each table in the registry.
* The route `GET /v1/tables/{table}/rows` lists the rows of one table.
* The route `POST /v1/tables/{table}/rows` writes one row.
* The route `POST /v1/tables/{table}/cells` writes a group of cells.
* The JSON codec. It reads a request body and it writes a response.
* `ErrorResponse` holds a code and a message for a failed request.
* The request size limit. Kibtab rejects a body above one mebibyte with
  the code `payload_too_large` and the status 413.
* The coverage gate in CI. It runs the tests against a real database.

## Security

None.

## Upgrade

1. Read the install guide before you install v0.5.0.
2. Keep your `DATABASE_URL` and your `KIBTAB_TABLES` value.
3. Send a request body of at most one mebibyte to a write route.
