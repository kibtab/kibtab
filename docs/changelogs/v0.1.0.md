# Kibtab v0.1.0

Released: Not released. Commit: none.

Version 0.1.0. This file holds the changes for the skeleton release.

## Added

* `README.md` is the landing page. It links to each guide under `docs/`.
* `CONTRIBUTING.md` holds the steps to send a change.
* `CODE_OF_CONDUCT.md` holds the terms for taking part.
* `SECURITY.md` holds the private route for a vulnerability.
* `.github/ISSUE_TEMPLATE/` holds the forms for a bug, a feature, and a
  security report.
* `docs/install.md` holds the install and build steps.
* `docs/licence.md` holds the terms for Kibtab and the skill.
* `docs/conventions.md` holds the code, the documentation, and the scope rules.
* `docs/testing.md` holds the kinds of test and the coverage rules.
* `docs/releasing.md` holds the version, the gate, and the release steps.
* `scripts/docs-check.py` runs under `make docs-check`. It checks the sentence
  length and the banned words.
* `docs/ste100/index.md` holds the approved Technical Names.
* `docs/ste100/` holds one lexicon for each category.
* `air.toml` makes `air` rebuild on a change in `internal/` or `cmd/`.
* `Makefile` holds `build`, `install`, `run`, `test`, `vet`, and `lint`. It
  holds `fmt`, `tidy`, `watch`, `cover`, and `bench`. It holds `docs-check`,
  `notice-check`, `check`, `release-check`, `tag`, and `tools`.
* `.gitignore` covers the build, the coverage, and the profile output.

None.
