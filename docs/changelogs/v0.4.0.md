# Kibtab v0.4.0

Released: [v0.4.0](https://github.com/kibtab/kibtab/releases/tag/v0.4.0).

Version 0.4.0. This file holds the changes for the write path release.

## Added

* `internal/core/services/` holds `SyncService`. It writes a `SyncPayload`.
* `SyncService.Sync` groups the delta by row.
* `SyncService.Sync` writes each row group in one transaction.
* `SyncService.Sync` compares the payload version to the table version
  before the write.
* `SyncService.Sync` returns a `ConflictError` when the versions differ.
* `SyncService.Sync` maps each value through the `Dialect` port.
* `GroupByRow` groups a delta by row key. It keeps the delta order.
* `domain.ConflictError` names a write that used a stale version.
* A race test. Two writes use one version. One write wins.
* A rollback test. A failed group stops no other group.

## Security

None.

## Upgrade

1. Read the install guide before you install v0.4.0.
2. Keep your `DATABASE_URL` and your `KIBTAB_TABLES` value.
3. No data migration runs.

## Notes

The write path is not reachable from a transport yet.
The REST API lands at v0.5.0.

The version bump and the audit row land at v0.7.0.
Until then, the write path compares the version only.
