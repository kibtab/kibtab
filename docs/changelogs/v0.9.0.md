# Kibtab v0.9.0

Released: Not released. Commit: none.

Version 0.9.0. This file holds the changes for the hardening release.

## Added

* `make test` starts the testing database and it runs each test.
  The coverage summary shows 100% for each package.

## Changed

* `make test` stops the testing database when the run ends.
* The targets `cover`, `coverage-svg`, `cover-html`, and `cover-verify`
  share one run. It starts the database.
* The integration tests run in `make test`, not in `make cover-verify`
  only.
* `make test` reads the same port and the same user as the gate.

## Fixed

* `make test` skipped the integration tests, so the PostgreSQL adapter
  reported 79.6% coverage.
* `make postgres-start` failed when a database already answered on the
  port. It reuses that database now.
* `make postgres-start` reported success when the instance did not
  start. It fails now and it names the log file.
* `make postgres-stop` left a container behind when the host also had a
  local installation. It stops both now.
* `make coverage-svg` and the other coverage targets skipped the
  integration tests, so the badge reported 92.3%.

## Security

None.

## Upgrade

1. Install PostgreSQL or Docker before `make test`. Without either, the
   integration tests skip.
2. Run `make test` in the repository root.
3. Run `make cover-verify` before you send a change.

## Notes

The coverage floor stays in `make cover-verify`.
Both targets start the database on the port 5433.
