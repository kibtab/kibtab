# Kibtab v0.8.0

Released: Not released. Commit: none.

Version 0.8.0. This file holds the changes for the packaging release.

## Added

* `KIBTAB_HOST` sets the address that the instance binds.
  The default stays `127.0.0.1`.
* The container sets `KIBTAB_HOST=0.0.0.0`. Caddy then reaches the instance.
* `Dockerfile` builds the instance on a `scratch` base without a C compiler.
* `docker-compose.yml` starts Caddy, Kibtab, and PostgreSQL.
* The health route answers through the proxy on the port 443.
* `Caddyfile` holds the domain and the rate limit for one client address.
* The compose file builds the proxy with the `rate_limit` module.
* Each archive holds `docs/THIRD_PARTY_NOTICES.md` and the licence.
* `checksums.txt` holds the digest of each archive.
* The release body links the changelog file of the tag.
* The self-hosting guides describe the stack and each setting.
* A unit test reads each deploy file and it checks each setting.
* The end-to-end test starts the stack and it writes a row through the
  proxy. It checks the audit row, the version, and the conflict.
* The target `make release-check` runs `goreleaser check`.

## Changed

* Every Make target that calls the Go tool sets `CGO_ENABLED=0`.
* `make watch` reads `air.toml` at the repository root. It is the only
  reload file.
* The compose service for the instance is `kibtab`.
* `PORT` keeps the default 8080. `KIBTAB_HOST` names the address.

## Fixed

* The instance bound the loopback address only.
  A container in the stack could not serve the proxy.
* The compose file did not pass `KIBTAB_TABLES` to the instance.
  The route `GET /v1/tables` returned an empty list.

## Security

None.

## Upgrade

1. Run `make tools` once. The install of each tool now sets `CGO_ENABLED=0`.
2. Keep your `air.toml` at the repository root. Do not add a second reload
   file.
3. Set `POSTGRES_PASSWORD` in a `.env` file before the first start.
4. Set `KIBTAB_DOMAIN` in the `.env` file. Caddy requests the certificate
   for that domain.
5. Run `docker compose up -d --build` to start the stack.
6. Keep `KIBTAB_HOST` at the default on a bare host. The proxy holds the
   public port.
7. Run `make check` before you build a release.

## Notes

The default `KIBTAB_HOST` is `127.0.0.1`. Only a container sets `0.0.0.0`.

The rate limit stays at the edge. The instance holds no rate limit code.
Caddy answers 120 requests a minute for one address.
A later request gets the status 429.
The port 80 serves the redirect to the port 443.
