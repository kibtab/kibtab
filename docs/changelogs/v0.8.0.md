# Kibtab v0.8.0

Released: Not released. Commit: none.

Version 0.8.0. This file holds the changes for the packaging release.

## Added

* `make watch` reads `air.toml` at the repository root. It is the only
  reload file.
* The target `make tools` installs each tool with `CGO_ENABLED=0`.

## Changed

* Every Make target that calls the Go tool sets `CGO_ENABLED=0`.
* The targets `fmt`, `lint`, `tidy`, and `tools` follow that rule now.

## Security

None.

## Upgrade

1. Run `make tools` once. The install of each tool now sets `CGO_ENABLED=0`.
2. Keep your `air.toml` at the repository root. Do not add a second reload
   file.
3. Run `make check` before you build a release.

## Notes

GoReleaser sets `CGO_ENABLED=0` in `.goreleaser.yaml`.
The GoReleaser build holds one environment block for each build.
