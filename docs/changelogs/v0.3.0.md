# Kibtab v0.3.0

Released: [v0.3.0](https://github.com/kibtab/kibtab/releases/tag/v0.3.0).

Version 0.3.0. This file holds the changes for the PostgreSQL adapter release.

## Added

* `internal/adapters/driven/postgres/` holds the PostgreSQL adapter.
  It implements the `Dialect`, `RowRepository`, `TableRegistry`,
  and `TransactionRunner` ports.
* `internal/adapters/driven/contracttest/` holds the shared
  `RowRepository` contract suite. Each engine adapter runs it. A second
  adapter must not copy it.
* `Dialect.Page` returns the paging clause and its arguments. The port
  declared the method and `plan.md` required it, but no adapter built it.
* The CI job runs a PostgreSQL service. The integration tests reach it
  through `KIBTAB_TEST_DATABASE_URL`.
* `EnvKeyTestDatabaseURL` names the environment variable for the tests.
* `Engine` wires the connection pool, the dialect, the registry, the
  repository, and the runner together.
* `NewEngine` reads `DATABASE_URL`, `KIBTAB_TABLES`,
  `KIBTAB_DB_MAX_CONNS`, and `KIBTAB_DB_MIN_CONNS`.
* `Migrate` creates the `_kibtab_meta` schema with `table_versions`
  and `audit_log` tables under an advisory lock.
* The `run` function in `cmd/kibtab/main.go` builds and migrates the
  engine when `DATABASE_URL` is set.

## Changed

* `TransactionRunner` uses a `txBeginner` interface instead of
  `*pgxpool.Pool` directly. This makes the commit and rollback error
  paths unit-testable without a real database.
* `RowRepository.Read` takes its paging clause from the `Dialect` port
  instead of writing `LIMIT $1` in the adapter.
* `docs/THIRD_PARTY_NOTICES.md` links each dependency licence in its
  upstream repository. It holds no copy of a third party licence.

## Fixed

* The integration tests skipped in CI. No job supplied a database, so a
  defect in the adapter could reach `main`.
* `testEnvURL` returned `KIBTAB_TEST_DATABASE_URL` unchanged. Every test
  then ran in the same database and fought over the same table names.
* `notice-check.py` skipped the direct dependencies. A lone require on one
  line never matched, so `pgx/v5` had no row and the check still passed.
* `notice-check.py` read a version with a trailing newline. The pattern
  excluded a space but not a newline.

## Upgrade

1. Install PostgreSQL 12 or later.

   Create a database and grant a user full access to it.

   ```bash
   createdb kibtab
   ```

2. Set `DATABASE_URL` to the database URL.

   ```bash
   export DATABASE_URL=postgres://localhost:5432/kibtab
   ```

3. Start Kibtab. It runs the migrations on start-up.

   ```bash
   kibtab
   ```

## Notes

The adapter reaches 100% coverage. `make cover-verify` passes.

The default PostgreSQL credentials depend on the local setup. The
default user is the operating-system user (usually `postgres`
when using `sudo -u postgres`). Kibtab uses the URL in `DATABASE_URL`
to connect. Change the URL to change the credentials.

```bash
export DATABASE_URL=postgres://myuser:mypass@localhost:5432/kibtab
```
