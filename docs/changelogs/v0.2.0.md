# Kibtab v0.2.0

Released: Not released. Commit: none.

Version 0.2.0. This file holds the changes for the domain and ports release.

## Added

* `internal/core/domain/` holds the pure Go domain types:
  `TableMetadata`, `CellValue`, `CellDelta`, `SyncPayload`, `SyncResult`,
  and `ValidationError`.
* `internal/core/ports/` holds the port interfaces:
  `RowRepository`, `TableRegistry`, `AuditWriter`, `Dialect`,
  `TransactionRunner`, `Clock`, and `SyncService`.
* `internal/core/services/` holds the domain services for validation,
  the batch merge, and the version compare.
* A table-driven test for each service in `internal/core/services/`.
* The core test suite runs without a container.
* `docs/architecture.md` holds the layers and the port contract.
* A CI step that fails the build on a driver import in the core.
* A CI step that fails the build when the core names an engine or a client.
* `.github/workflows/release.yml` runs GoReleaser on a version tag and
  links the changelog in the release notes.
* The coverage floor holds at 100% for the module. `make cover-verify`
  passes with no uncovered statement.
* The start-up wiring in `cmd/kibtab/` sits in the `run` and `newMux`
  functions. A test starts the instance and drives `GET /healthz`.

None.
