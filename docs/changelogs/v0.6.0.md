# Kibtab v0.6.0

Released: Not released. Commit: none.

Version 0.6.0. This file holds the changes for the Office.js client release.

## Added

* `client/excel/` holds the Office.js taskpane.
* The taskpane sends a `SyncPayload` and shows the result.
* The taskpane shows a conflict message. It offers a reload.
* The taskpane groups a burst of edits into one payload.
* `client/excel/manifest.xml` holds the add-in manifest.
* The client build. It uses `esbuild`.
* `make client-build` builds the taskpane bundle.
* `make client-zip` zips the client output into `kibtab-taskpane.zip`.
* `pnpm` manages the client dependencies. The lockfile is `client/excel/pnpm-lock.yaml`.
* `docs/THIRD_PARTY_NOTICES.md` holds rows for `office-js`, `typescript`, and `esbuild`.

## Fixed

* The instance mounts the REST routes. The taskpane reaches the write path.
* `client/excel/pnpm-lock.yaml` sits in the client folder. The client CI
  job finds it.

## Security

None.

## Upgrade

1. Read the install guide before you install v0.6.0.
2. Keep your `DATABASE_URL` and your `KIBTAB_TABLES` value.
3. Build the client with `make client-build`.
4. The taskpane bundle is `client/excel/dist/taskpane.js`.
