# Licence

Version 0.0.0-docs. This document holds the licence terms for Kibtab.

Read [LICENSE](../LICENSE) for the full text of the Apache License 2.0.
Read [the third party notices](THIRD_PARTY_NOTICES.md) for each dependency.

## The Engine

The whole Kibtab repository uses the Apache License 2.0.
That licence covers the engine, the client, the docs, and the plans.
It covers every file that Kibtab wrote.

| Item | Value |
| --- | --- |
| Licence | Apache License 2.0 |
| Full text | `LICENSE` at the repository root |
| Scope | Every file that Kibtab wrote |
| Change at a later version | None. The licence does not change. |

The repository holds one folder of copied work.
The folder `skills/simple-english/` holds a copy from another project.
That copy keeps the licence of its author.
Read [the vendored skill](#the-vendored-skill) below.

The Apache License 2.0 lets a user do these things.

* Use the engine for any purpose, including a commercial one.
* Study the engine and change it.
* Distribute the engine and any change.
* Use the engine in a closed product.

The licence asks for these things.

* Keep the copyright notice.
* Keep the licence text.
* State the changes that the user made.
* Keep the attribution notices in the notices file.

## Open Core

Kibtab is an open core project.
Every file that Kibtab wrote stays open under the Apache License 2.0.
The licence does not change at v1.0.0.
It does not change at any version.

## The Vendored Skill

The writing skill under `skills/simple-english/` uses the MIT licence.
Read `skills/simple-english/LICENSE` for the full text.

The skill is a separate work.
It keeps its own licence.
It does not change the licence of the engine.

## Third Party Software

The engine links to third party libraries.
Each library keeps its own licence.

Read [the third party notices](THIRD_PARTY_NOTICES.md) for the list.

The notices file holds the following.

* The module name for each dependency.
* The licence for each dependency.
* The use of each dependency in Kibtab.
* The commit for each vendored project.

## Apache Notice Requirement

The Apache License 2.0, section 4 asks for the attribution notices.
Kibtab keeps that requirement for each dependency under the Apache Licence.

Read the requirement in [the third party notices](THIRD_PARTY_NOTICES.md).

## Contributions

A contribution uses the Apache License 2.0.
Send a patch. Do not send a licence change.
A pull request needs a passing build.

Do not edit the copied work under `skills/simple-english/`.
A change to that folder needs a new pinned commit.
Read `skills/simple-english/VENDOR.md` for the refresh steps.

Read [AGENTS.md](../AGENTS.md) before you contribute.
